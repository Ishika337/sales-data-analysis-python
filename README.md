# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales data using Python to understand revenue trends, product performance, and customer purchasing behavior.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed
- Dataset exploration and basic data cleaning
- Revenue analysis by product and category
- Monthly sales trend visualization
- Average order value analysis
- Customer order-size analysis

## Key Findings
- Laptops generated the highest revenue, according to the notebook analysis.
- Electronics was the leading sales category.
- Sales peaks were observed in November, October, and July.
- Average order value was approximately $1,106.
- Customers purchased approximately 2.5 items per order.

## Skills Demonstrated
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Interpreting business insights


## Data Quality Checks

- Checked for missing values in each column.
- Checked for duplicate rows.
- Reviewed data types and numerical summaries.

## How to Run

1. Download the notebook and `sales_data.csv` from this repository.
2. Open the notebook in Google Colab.
3. Upload `sales_data.csv` to the Colab session if required.
4. Run the notebook cells in order.
